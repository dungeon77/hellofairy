# HelloFairy Home Assistant Integration

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://github.com/hacs/integration)

Компонент для управления лампами Hello Fairy (LED-лампами с BLE управлением) через Home Assistant.

## Особенности

- **Полное управление цветом**: Поддержка RGB, HSV/HSB цветовых моделей
- **115+ предустановленных эффектов**: Новый год, Хэллоуин, Пасха, сердечки, утки, растения, флаги и многое другое
- **4 музыкальных режима**: Энергия, Ритм, Шар, Спектр с регулируемой чувствительностью
- **Управление скоростью и направлением** для анимированных эффектов
- **Автоматическое переподключение** при потере соединения BLE
- **Поддержка нескольких ламп** одновременно

## Поддерживаемые устройства

Лампы Hello Fairy с BLE управлением, такие как:
- Hello Fairy LED лампы с поддержкой сцен
- Устройства с UUID управления: `49535343-8841-43f4-a8d4-ecbe34729bb3`

## Установка

### Через HACS (рекомендуется)

1. Убедитесь, что у вас установлен [HACS](https://hacs.xyz/)
2. В HACS перейдите в **Integrations**
3. Нажмите три точки (⋮) в правом верхнем углу → **Custom repositories**
4. Добавьте URL: `https://github.com/dungeon77/hellofairy`
5. Выберите категорию: **Integration**
6. Нажмите **ADD**
7. Теперь найдите "HelloFairy" в HACS и установите
8. Перезапустите Home Assistant

### Ручная установка

1. Скачайте последний релиз
2. Скопируйте папку `custom_components/hellofairy` в директорию `custom_components/` вашего Home Assistant
3. Перезапустите Home Assistant

## Конфигурация

### Через UI (рекомендуется)

1. После установки перейдите в **Настройки** → **Устройства и службы** → **Добавить интеграцию**
2. Найдите "HelloFairy"
3. Следуйте инструкциям по настройке

### Через YAML

Добавьте в `configuration.yaml`:

```yaml
hellofairy:
  scan_interval: 30  # Опционально: интервал сканирования в секундах
```
## Использование
После настройки интеграция автоматически обнаружит доступные лампы Hello Fairy в сети BLE. Каждая лампа будет представлена как светильник (light entity) в Home Assistant со следующими возможностями:

### Основные функции:
Включение/выключение

Изменение яркости (0-100%)

Выбор цвета (RGB, оттенок, насыщенность)

Выбор эффектов из 115+ предустановленных сцен

Музыкальные режимы с регулировкой чувствительности

Управление скоростью анимации

Изменение направления прокрутки эффектов

Доступные эффекты (категории):
🎄 Новый год (6 эффектов)

🎃 Хэллоуин (6 эффектов)

🥚 Пасха (5 эффектов)

❤️ Сердечки (5 эффектов)

🦆 Утки (5 эффектов)

🌿 Растения (5 эффектов)

🏳️ Флаги (10 стран)

🎭 Карнавал (6 эффектов)

⛪ Религия (4 эффекта)

👨‍👩‍👧‍👦 Семья (5 эффектов)

🦕 Животные (4 эффекта)

💻 Электроника (28 эффектов)

🎆 Салюты (8 эффектов)

🏠 Дом (7 эффектов)

🎵 Музыкальные режимы (4 режима)

Музыкальные режимы:

Шар (Ball) - шары, реагирующие на басы

Спектр (Spectrum) - визуализация частотного спектра

## Автоматизации
Компонент полностью интегрируется с Home Assistant автоматизациями:

```yaml
automation:
  - alias: "Включить новогодний режим вечером"
    trigger:
      platform: time
      at: "18:00:00"
    action:
      - service: light.turn_on
        target:
          entity_id: light.hello_fairy_lamp
        data:
          effect: "new_year_tree"
          brightness: 80

  - alias: "Музыкальный режим при проигрывании музыки"
    trigger:
      platform: state
      entity_id: media_player.living_room
      to: "playing"
    action:
      - service: light.turn_on
        target:
          entity_id: light.hello_fairy_lamp
        data:
          effect: "music_energy"
          brightness: 60
```
## Требования
Home Assistant 2023.1.0 или выше

Bluetooth адаптер с поддержкой BLE (на системе с Home Assistant)

Лампы Hello Fairy в радиусе действия Bluetooth (≈10 метров)

## Технические детали
Протокол: BLE (Bluetooth Low Energy)

UUID управления: 49535343-8841-43f4-a8d4-ecbe34729bb3

Библиотеки: bleak, bleak-retry-connector

Язык: Python 3.10+
